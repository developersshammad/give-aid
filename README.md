# Give-AID – NGO Website (Aptech eProject)

**Live demo:** see the Vercel link in the repository's About section.

- `site/` – the live demo that is deployed on Vercel. All public pages, donation with card validation and receipt, member area and the full admin panel (with the AI Programme Planner) run in the browser with sample data.
- `GiveAid/` + `GiveAid.sln` – the real application: ASP.NET Core MVC 8, C#, SQL Server, Entity Framework Core 8. Open `GiveAid.sln` in Visual Studio 2022 and press F5.
- `PROJECT_README.md` – full setup, features, credentials and deployment guide.
